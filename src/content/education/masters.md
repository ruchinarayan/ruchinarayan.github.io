#### Master's in Computer Science

<b>Courses: </b>

- <b>Foundations of Software Engineering:</b> Learned about Software requirements writing user stories, design (UML), collaborating and writing code along with the team member's using Ruby on Rails, testing using  modern testing techniques and maintenance, Configuration management using Github
- <b>Cryptography and Data Security:</b> Learned about Data confidentiality, Public key cryptography and Data integrity
- <b>Foundations of Computing:</b> Information processing, Recognition, Generation and Compaction, Finite Memory models, Unilimited memory: Turing machine, Computational complexity
- <b>Program Comprehension:</b> Learned about Software engineering activities and fundamental of program comprehension.
- <b>Operating / Distributed System:</b> About operatiing system architecture for both centralized and disctributed storage and file systems.
- <b>Algorithms and Problem Solving:</b> Basics of algorithm, complexity calculations, divide and conquer, Dynamic programming design, Linear programming and NP completeness.
- <b>Web Services and the Internet:</b> REST and SOAP web services
- <b>Natural Language Processing:</b> Intruduction of NLP techniques, Text processing, n-gram language models, Text classification, Logistic regression
- <b>Independent Studies Comp Science: </b> Master's project Teaching Software Design Patterns with Active Learning and Peer Review
